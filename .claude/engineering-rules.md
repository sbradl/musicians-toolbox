# Engineering rules

Task runner: mise

## Stacks

- **rust** — Rust 1.99.1, edition 2024 · no framework · `cargo test` · cargo (desktop library: cargo-zigbuild) · `/` (Cargo workspace)
- **kotlin** — Kotlin 2.4.21 (KMP, jvm + android) · Compose Multiplatform 1.9.3 desktop + Android (AGP 9.5.1, minSdk 29, targetSdk 36) · JUnit 4 + Compose ui-test (instrumented on Android) · Gradle 9.8.2 · `apps/*/ui/`, `build-logic/`
- **github-actions** — GitHub Actions workflows · `.github/workflows/`

## Static analysis and linting

| Stack | Category | Tool | Ruleset |
| --- | --- | --- | --- |
| rust | Linter | Clippy | pedantic (except `missing_errors_doc`, `missing_panics_doc`: docs not required, user decision; `must_use_candidate`, `return_self_not_must_use`: rustc `unused_results` already flags every ignored return value, user decision) + nursery + cargo + restriction picks (`allow_attributes`, `allow_attributes_without_reason`, `undocumented_unsafe_blocks`, `todo`, `unimplemented`, `dbg_macro`, `print_stdout`, `print_stderr`, `unwrap_used`, `expect_used`, `panic`, `cognitive_complexity`) |
| rust | Linter | Opengrep | own rules (`.opengrep/`), offline |
| rust, kotlin | Linter | `tools/blank-lines/check.awk` | blank line before every `if` and `return` unless it opens its block or continues an expression; implicit returns stay a review rule |
| rust | Coverage rule | `tools/fuzz-targets/check.sh` | every type saving a file through `save_whole_or_nothing` is named by a fuzz target (ADR 0005) |
| rust | Fuzzing | cargo-fuzz (nightly, own workspace `apps/tabfinder/adapters/fs/fuzz/`) | `fuzz:tabfinder`, 60 s per target, 5 s per input; fuzz crate carries a copy of the root lint tables and is linted in `lint:clippy` (user decision) |
| rust | Formatter | rustfmt | defaults |
| rust | Type strictness | rustc lint levels | allowed-by-default extras except `missing_docs` (docs not required, user decision) + lint groups; `warn` in manifests, `-D warnings` in `lint:clippy` |
| rust | Complexity | Clippy thresholds | cognitive 15, lines 25, arguments 5, nesting 4, type complexity 250 |

| rust | Portability | `checkGlibcFloor` (Gradle, part of `check`) | the desktop Rust library (built with `cargo zigbuild` for `x86_64-unknown-linux-gnu.2.31`) needs glibc ≤ 2.31 |

Exceptions: `syn` 2 + 3 duplicate allowed (UniFFI; `deny.toml` skip, `clippy.toml` allowed-duplicate-crates); workspace path deps without version allowed (`allow-wildcard-paths`).
| rust | Architecture rules | cargo-deny bans | deny list with layer `wrappers` + network and async-runtime crates denied, `multiple-versions = "deny"`, `wildcards = "deny"` (allowlist mode cannot combine with wrappers) |
| rust | Dead code | rustc unused lints | `unused`, `unused_crate_dependencies`, `unreachable_pub` |
| kotlin | Formatter + linter | ktlint 1.8.0 | `ktlint_official` |
| kotlin | Type strictness | Kotlin compiler | `allWarningsAsErrors`, `extraWarnings` except generated UniFFI bindings (own module `apps/<app>/adapters/ffi`, loosened by the user: we do not control their code) |

Not picked: Kotlin linter, complexity, architecture and dead-code tools; GitHub Actions linter and formatter.

Layers (clean architecture dependency rule: dependencies point inward only):
- `mt-library` (context) ← application, presentation (ffi reaches the domain through presentation)
- `mt-tabfinder-application` ← presentation, fs, ffi
- `mt-tabfinder-presentation` ← ffi
- `mt-tabfinder-fs` (desktop driven adapters) ← ffi
- `mt-tabfinder-ffi` ← nothing (cdylib only, so no Rust crate can link it; consumed by Kotlin `ui/`)
- `uniffi` ← ffi, uniffi-bindgen only (ADR 0002)
- Kotlin: `ui:desktop`, `ui:android` → `ui:shared` (Gradle rejects the reverse as a cycle)

Run: `mise run lint`

## Security analysis

| Stack | Category | Tool | Ruleset |
| --- | --- | --- | --- |
| rust, kotlin, github-actions | SAST | Opengrep | broadest: `p/default`, `p/owasp-top-ten`, `p/security-audit`, `p/rust`, `p/kotlin`, `p/github-actions` (Semgrep registry rules: internal use only, fetched at run time, never committed); except `exported_activity`: the launcher activity must be exported, user decision |
| rust, kotlin | Dependency vulnerabilities | Trivy fs | all severities incl. UNKNOWN; exceptions in `.trivyignore.yaml` with statement + `expired_at` |
| rust | License compliance | cargo-deny licenses | strict: `include-dev`, `unused-allowed-license = "deny"`, confidence 0.93 |
| kotlin | License compliance | Gradle-License-Report | allowlist, `jvmRuntimeClasspath`, `androidRuntimeClasspath` (KMP modules with an Android target; the Android app module itself is not checked: the plugin cannot resolve its variants) |
| rust, kotlin | SBOM | Trivy | CycloneDX, generated by `package:tabfinder` |
| rust, kotlin | Third-party notices | cargo-about, Gradle-License-Report text | `THIRD-PARTY-NOTICES.txt` in the app image and APK assets; `package:tabfinder` checks both |
| all | Secret scanning | Trivy secret | built-in rules (working tree only, not git history) |

License allow-list: MIT, Apache-2.0, Unicode-3.0, MPL-2.0 (only what is in use; ADR 0005's list caps what may be added)
SBOM: CycloneDX, `build/package/tabfinder-sbom.cdx.json`, uploaded with the CI packaging artifacts
Run: `mise run security`; no `dast` (no HTTP)

Kotlin dependencies are visible to Trivy through Gradle dependency locking (`gradle.lockfile`, refresh with `./gradlew dependencies --write-locks` per project).

## Entry points

`Main.kt` and `MainActivity` only wire tested pieces together; no failing test is needed for a wiring line. The packaged-app start in CI (`smoke:tabfinder`, `test:android`) and the release-check wizard cover it. A decision (an `if`, a wait, a fallback) moves into a tested class first.
