# Music kernel

The small set of musical values several contexts share by agreement. It holds values only, never domain behaviour beyond naming and arithmetic.

## Language

**Pitch**:
A sounding pitch, such as E2 or F♯4; enharmonic spellings name the same Pitch.
_Avoid_: Tone, MIDI note

**Duration**:
How long something lasts in musical time, as a fraction of a whole note.
_Avoid_: Length, ticks

**Time signature**:
The metre of a bar, such as 4/4 or 7/8.
_Avoid_: Meter, measure signature

**Tuning**:
The open Pitches of an instrument's strings, from lowest to highest, with its name when it has one (E Standard, Drop D) or Custom when it has none.
_Avoid_: String set
