# Analysis

Facts derived from a Score, such as which techniques each part of a song uses.

## Language

**Role**:
What a Part plays: drums, bass, rhythm or lead.
_Avoid_: Instrument, track type

**Part**:
Everything a Score gives one Role; rhythm and lead are told apart per bar, not per track.
_Avoid_: Track, voice

**Tag**:
A technique or characteristic found in a Part, such as fast, syncopated, odd meter, sweeps or double kick.
_Avoid_: Label, feature
