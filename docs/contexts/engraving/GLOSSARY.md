# Engraving

Laying out music notation so it can be drawn. It knows notation, not the models notation is made from.

## Language

**Engraving input**:
The published description of what to engrave: staves, voices, durations, noteheads. Other contexts translate into it.
_Avoid_: Model, song

**Display list**:
The laid-out notation: lines, curves, glyphs and text at positions, ready to draw.
_Avoid_: Render tree, view
